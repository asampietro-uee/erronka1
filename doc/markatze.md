# Markatze-lengoaiak

Atal honetan web interfazearen garapena, egitura eta estiloen aplikazioa deskribatzen dira.

## 1. Web Egitura (HTML5)
- Egitura semantikoa: `<header>`, `<nav>`, `<main>`, `<section>`, `<article>`, `<footer>`.
- Irisgarritasuna (a11y) eta SEO oinarriak.
- Inprimakiak eta datu-baliozkotze estandarrak.

## 2. Diseinua eta Estiloak (CSS3)
- Maketazio aurreratua: **Flexbox** eta **CSS Grid**.
- Diseinu moldagarria (**Responsive Design**): `@media` kontsultak pantaila mota ezberdinetara egokitzeko.
- Aldagai pertsonalizatuak (CSS Custom Properties) eta trantsizio leunak.

## 3. Baliozkotzea eta Estandarrak
- W3C estandarren araberako kodearen baliozkotzea.
- Nabigatzaileen arteko bateragarritasuna (Cross-browser testing).
